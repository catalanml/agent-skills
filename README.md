# claude-skills

Personal skills for Claude Code.

Install one on a machine:

    git clone git@github.com:catalanml/claude-skills.git ~/projects/claude-skills
    ln -s ~/projects/claude-skills/building-verification-loops ~/.claude/skills/

| Skill | Use |
|---|---|
| `building-verification-loops` | Choosing checks, keeping them honest, gates and review rules |
